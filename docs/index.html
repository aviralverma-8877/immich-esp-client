Immich Frame

A small ESP32 photo frame that shows a slideshow from your own Immich server.

Install

Your browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. Web Serial needs a secure page: open this site over https.

Plug the frame in over USB-C, press Connect, pick the serial port (usually "USB-SERIAL CH340") and choose Install. Erasing the device on first install is recommended.

Before you start

  • Hardware: the ESP32 RJ9 Adapter board (ESP32-WROOM-32, 4 MB flash) with a 240×320 ST7789 display. Other ESP32 + ST7789 builds with the same wiring also work.
  • Browser: Chrome or Edge on Windows, macOS, Linux or ChromeOS. Phones and Firefox/Safari can't flash.
  • Cable: a USB-C cable that carries data, not a charge-only one.
  • Driver: if no serial port shows up on Windows or macOS, install the CH340 USB driver.

After installing

  1. The frame starts a setup WiFi network called ImmichFrame-XXXX and shows a QR code. Scan it with your phone to join.
  2. The setup page opens by itself (or go to http://192.168.4.1). Pick your home WiFi, enter your Immich server URL, for example http://192.168.1.10:2283, and an API key.
  3. Press Connect. The frame checks the WiFi and your Immich login, shows its new address and restarts.
  4. Open that address (or http://immich-frame.local) to choose what to show: all photos, an album, a person, a tag or favourites, plus order, interval, transitions and orientation.

Immich checklist

API keyCreate one under Account Settings → API Keys. It needs read access to assets, albums, people, tags and your user.
PreviewsThe frame shows Immich's preview images, which must be JPEG (the default, under Administration → Settings → Image).
Skipped photosIf the portal reports photos skipped as "not a valid JPEG", those preview files are damaged on the server. Regenerate them with Administration → Jobs → Generate Thumbnails → All.
NetworkThe frame uses 2.4 GHz WiFi and must be able to reach the server's address.

Controls and troubleshooting

BTN1Next photo; hold for 1.2 s to pause or resume.
BTN2Previous photo.
Factory resetHold BOOT for 6 s, or hold BTN1 + BTN2 for 3 s while powering on.
Wrong coloursIn the portal use Display colours → Show test pattern and switch colour order or inversion until the bars match their labels.
Can't connectClose other serial monitors (Arduino, PlatformIO) using the port. If flashing still fails to start, hold BOOT while pressing Connect.
UpdatesRun this installer again, or upload a new firmware file from the portal's Device section.
